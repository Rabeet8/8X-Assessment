The issue you were experiencing on the Cinema Studio page is a classic browser security restriction called **CORS (Cross-Origin Resource Sharing)**.

Here is exactly what was happening:

When you use one of the pre-built "Demo Videos" (which are hosted on remote servers like Unsplash), the browser blocks our frontend code from directly downloading or manipulating that video file programmatically. This is a security measure built into Chrome/Safari to prevent websites from secretly downloading data from third-party domains without permission.

To fix the crash without needing a real backend rendering server, I split the export logic into two paths:

1. **When using a Demo Video (Remote):** Instead of the browser trying (and failing) to download the remote video, it now detects the remote URL, shows you a quick alert, and simulates the export by downloading a `.txt` file representing the "rendered scene data". (In a real app, you would send this data to a backend server to render and return the MP4).
2. **When you Upload your own Video (Local):** Because the video comes directly from your hard drive into the browser's memory, it bypasses all CORS security restrictions. When you upload a video and click Export, it successfully downloads the actual `.mp4` file back to your machine!
